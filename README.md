# FitTrack — Habit Tracker

A simple habit-tracking website designed to help users build consistent daily routines and monitor their progress.

## Features
- Track daily habits
- Mark habits as completed
- Monitor daily progress

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.

## Deployment
This website is deployed using Netlify and connected to GitHub.
